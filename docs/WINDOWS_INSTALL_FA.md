# نصب ChronoScalp روی ویندوز

این مسیر اصلی است: برنامه روی همان رایانهٔ شما نصب می‌شود. VPS لازم نیست. سود تضمین نمی‌شود. جزئیات شواهد در [BAZRASI_SADEGHANE_FA.md](BAZRASI_SADEGHANE_FA.md) است و سلب مسئولیت در [RISK_DISCLAIMER.md](RISK_DISCLAIMER.md).

این محیط ساخت (اگر لینوکس باشد) فایل `exe` نمی‌سازد. خروجی ویندوز را خود ویندوز یا workflow به نام `Windows installer` می‌سازد.

## پیش‌نیاز

- ویندوز ۶۴بیت و ورود با همان کاربری که برنامه را نصب می‌کند.
- Python لازم نیست اگر از `ChronoScalp-Setup.exe` استفاده کنید. برای ساخت نصب‌کننده از سورس، Python 3.11 و Inno Setup 6 لازم است.
- MetaTrader 5 نصب، و وارد همان حسابی که می‌خواهید (ترجیحاً دمو) شده باشد.
- XAUUSD و EURUSD در Market Watch دیده شوند. نام کارگزار ممکن است پسوند داشته باشد؛ در پنل همان نام را انتخاب کنید.
- در ساعاتی که ربات باید وصل بماند، Sleep و Hibernate را خاموش کنید. قفل صفحه اشکالی ندارد؛ خروج از کاربر (sign out) اتصال MT5 را می‌برد.

نصب‌کننده مدیر سیستم نمی‌خواهد. فایل‌ها در `%LOCALAPPDATA%\ChronoScalp` می‌نشینند. تنظیم و `.env` در `%APPDATA%\ChronoScalp` است، نه کنار فایل‌های نصب.

## ساخت نصب‌کننده روی ویندوز

در PowerShell، از ریشهٔ مخزن:

```powershell
choco install innosetup -y
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\windows\build_installer.ps1
```

اگر Chocolatey ندارید، Inno Setup 6 را از سایت خودش نصب کنید تا `ISCC.exe` در `C:\Program Files (x86)\Inno Setup 6\` باشد، بعد فقط اسکریپت ساخت را اجرا کنید.

ترتیب اسکریپت: ساخت `.venv`، نصب `requirements.txt` و PyInstaller، ساخت onedir رانر، ساخت onedir پنل، سپس کامپایل Inno. خروجی:

`dist\ChronoScalp-Setup.exe`

روی GitHub، workflow با نام `Windows installer` همین کار را روی `windows-latest` می‌کند و فایل را آرتیفکت PR می‌گذارد. اگر آن job قرمز ماند، علت را در لاگ همان job ببینید؛ یک اصلاح کافی است و حلقهٔ طولانی لازم نیست.

## نصب، میانبر، بالا آمدن خودکار

1. `ChronoScalp-Setup.exe` را اجرا کنید.
2. میانبرهای منوی استارت و دسکتاپ: پنل، شروع، توقف.
3. نصب، وظیفهٔ `ChronoScalpRunner` را در Task Scheduler برای **At logon** همین کاربر ثبت می‌کند. سطح Limited است و فقط وقتی این کاربر وارد شده اجرا می‌شود. سرویس ویندوز نیست.
4. وظیفه، رانر را با `--mode paper` بالا می‌آورد و برای همان فرآیند `CHRONOSCALP_CONFIRM_LIVE=no` می‌گذارد. ورود به معامله فقط داخل سشن لندن (`Europe/London`، ۰۸:۰۰–۱۳:۰۰) و نیویورک (`America/New_York`، ۰۸:۳۰–۱۱:۳۰) بررسی می‌شود. بیرون سشن رانر می‌تواند روشن بماند ولی دستور جدید نمی‌فرستد.

اولین اجرا اگر `.env` نباشد، از `.env.example` ساخته می‌شود و تأیید زنده `no` است. فایل موجود بازنویسی نمی‌شود.

## اتصال به MT5

1. ترمینال MT5 را باز کنید و به حساب وارد شوید.
2. میانبر پنل را بزنید. آدرس محلی پنل `http://localhost:8501` است.
3. در پنل، اتصال MT5 را با لاگین، رمز، سرور، و در صورت نیاز مسیر `terminal64.exe` ذخیره کنید. این مقدارها فقط در `%APPDATA%\ChronoScalp\.env` می‌مانند.
4. نمادهای مارکت‌واچ را در پنل انتخاب کنید. طلا کاتالوگ دلتا + سبک اپراتور + استرادل خبر دارد. یورو کاتالوگ سبک اپراتور + استرادل خبر دارد و در نمونهٔ قبلی دلتا رد شده است.
5. استارت را روی Paper بگذارید تا وقتی خودتان، بعد از خواندن گزارش، چیز دیگری بخواهید.

## آزمایشی در برابر زنده

| حالت | چه می‌کند |
|---|---|
| Paper | پر کردن شبیه‌سازی‌شده. پیش‌فرض نصب و پیش‌فرض وظیفهٔ ورود. |
| Live | سفارش واقعی روی حسابی که MT5 باز کرده. فقط اگر در `.env` مقدار `CHRONOSCALP_CONFIRM_LIVE` دقیقاً `yes` باشد. پنل این را فقط با اقدام صریح شما می‌نویسد. نصب‌کننده و وظیفهٔ logon آن را روشن نمی‌کنند. |

کیل‌سوئیچ (توقف ورود جدید، بدون بستن اجباری از این میانبر) همان فایل `STOP_TRADING` در `%APPDATA%\ChronoScalp\data\state` یا متغیر `CHRONOSCALP_STOP_TRADING=yes` است.

## توقف

میانبر Stop فرآیند رانر و پنل را می‌بندد و دادهٔ کاربر را پاک نمی‌کند. ورود بعدی دوباره paper را بالا می‌آورد، چون وظیفهٔ logon هنوز هست. برای اینکه بعد از ورود هم بالا نیاید، وظیفهٔ `ChronoScalpRunner` را در Task Scheduler غیرفعال کنید.

## حذف نصب

از «Uninstall ChronoScalp» یا Apps ویندوز. حذف، وظیفهٔ زمان‌بندی، میانبرها، و پوشهٔ نصب را برمی‌دارد. سؤال می‌پرسد که `%APPDATA%\ChronoScalp` (تنظیم، `.env`، ژورنال) هم پاک شود یا بماند. پاسخ منفی یعنی دادهٔ شما می‌ماند و می‌توانید بعداً دوباره نصب کنید. دیتابیسی برای مهاجرت در این مخزن نیست؛ حالت در فایل JSON همان پوشه است.

## اگر فقط سورس دارید

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
powershell -File scripts\windows\start_panel.ps1
powershell -File scripts\windows\start_runner.ps1
```

`scripts\start.bat` هنوز پنل سورس را باز می‌کند. برای رایانهٔ شخصی، نصب‌کننده مسیر پشتیبانی‌شده است.
