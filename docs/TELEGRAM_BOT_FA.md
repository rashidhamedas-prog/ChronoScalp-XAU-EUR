# راه‌اندازی ربات تلگرام ChronoScalp

هشدارهای معامله + **کنترل کامل** + **تنظیمات منومحور (بدون تایپ)** از تلگرام.

## ۱) ساخت بات در Telegram

1. [@BotFather](https://t.me/BotFather) → `/newbot`
2. توکن را در `.env` بگذارید: `TELEGRAM_BOT_TOKEN=...`
3. `/whoami` بزنید و `TELEGRAM_CHAT_ID` را ست کنید

## ۲) روشن کردن

```bat
python scripts\telegram_control_bot.py
```

VPS: Task `ChronoScalpWatchTelegram` یا همان اسکریپت.

## ۳) منوی اصلی

| دکمه | کار |
|---|---|
| وضعیت / سود / پوزیشن | مانیتور |
| استارت Paper / Live / توقف ربات | فرآیند (Stop همهٔ `run_live` را می‌کشد) |
| توقف ورود / ادامه ورود | kill switch — فرآیند روشن می‌ماند |
| لاگ / راهنما | پشتیبانی |
| **تنظیمات** | هاب کامل تنظیمات |

## ۴) تنظیمات — فقط از منو (بدون تایپ)

مسیر: **تنظیمات**

| بخش | کار |
|---|---|
| خلاصه تنظیمات | وضعیت فعلی اتصال + نماد + استراتژی + ساعات + ریسک |
| اتصال | بروکر MT5/OANDA · Paper/Live · تست · تأیید Live |
| کنترل | میان‌بر به نماد/استراتژی/ساعات/ریسک |
| **نمادها** | تیک ✅/⬜ روی هر نماد → «ذخیره نمادها». طلا: دلتا + استرادل خبر · یورو: دلتا (فید/پولبک) + استرادل خبر |
| **استراتژی نمادها** | فقط نمایش. انتخاب جداگانه وجود ندارد |
| **ساعات معامله** | سشن لندن/آمریکا یا ۲۴ ساعته |
| **ریسک معامله** | ۰٫۵٪ / ۱٪ / ۱٫۵٪ (سقف امن ۱٪) · قفل ضرر روزانه · **یادگیری از اشتباه روشن/خاموش** |
| **اعلان معامله** | پیام فوری هنگام باز شدن معامله به یک آی‌دی جدا (پیش‌فرض `@taranomrashid`) · روشن/خاموش · تغییر آی‌دی · ارسال تست |
| تأیید Live روشن/خاموش | گیت `CHRONOSCALP_CONFIRM_LIVE` |

دکمه‌های «یادگیری از اشتباه» فقط `risk.mistake_memory.enabled` را در `runtime_overrides.yaml` تغییر می‌دهند؛ سقف ۱٪ هر معامله و ۳٪ ضرر روز را شل نمی‌کنند. بعد از تغییر، ربات را Stop سپس Start کنید. Live همچنان فقط با تأیید Live روشن استارت می‌شود.

**اعلان معامله:** به‌محض پر شدن پوزیشن یک پیام به گیرندهٔ تنظیم‌شده می‌رود. پیش‌فرض `@taranomrashid` است و از منو عوض می‌شود. گیرنده باید همین ربات را Start کرده باشد؛ برای کاربر خصوصی معمولاً `chat_id` عددی لازم است. بعد از تغییر آی‌دی، ربات معامله را Stop سپس Start کنید.

رمز MT5/OANDA فقط در ویزارد «بروکر MT5/OANDA» تایپ می‌شود (اجباری برای سکرت).

بعد از هر ذخیره: ربات را **Stop** سپس **Start** کنید. `/status` منبع تنظیم را نشان می‌دهد. تغییر overlay تا Stop/Start اعمال نمی‌شود.

`/pnl` گزارش جدا برای هر استراتژی می‌دهد (تعداد، نرخ برد، سود خالص) به‌علاوه جمع پورتفوی. مقایسهٔ استراتژی‌ها بر اساس R است نه حجم دلار.

## ۵) دستورات اختیاری (اتوماسیون)

| دستور | کار |
|---|---|
| `/symbols XAUUSD,EURUSD` | CSV (اختیاری؛ منو ترجیح داده می‌شود) |
| `/strategies` | نمایش کاتالوگ هر نماد (قابل تغییر نیست) |
| `/hours london_ny\|always_on_24h` | ساعات |
| `/risk 0.5\|1\|1.5` | ریسک |
| `/mistake_memory on\|off` | یادگیری از اشتباه |
| `/notify_id @user` یا عدد | آی‌دی گیرندهٔ اعلان باز شدن معامله |
| `/notify_test` | ارسال پیام تست به همان گیرنده |
| `/set_mt5` / `/set_oanda` | سکرت‌ها |

## ۶) امنیت

- فقط `TELEGRAM_CHAT_ID` مجاز است
- Live بدون تأیید Live روشن استارت نمی‌شود
- Kill Switch مستقل از توقف فرآیند است (`/halt` یا «توقف ورود»). `/stop` و «توقف ربات» خود فرآیند را خاموش می‌کنند.
- اگر ربات از قبل روشن باشد، استارت Paper/Live اول آن را Stop می‌کند بعد دوباره بالا می‌آورد.
