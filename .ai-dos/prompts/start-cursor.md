# Start in Cursor

Follow the repository root `AGENTS.md` and `.cursor/rules/ai-dos.mdc`. Read `.ai-dos/ai-dos.yaml`, project status, active tasks, and handoff before acting.

Default to Implementer for the task explicitly assigned to you. Verify that you are the recorded owner and that every file you will edit is in your `file_claims` and not claimed elsewhere. If ownership is absent or conflicting, stop and report the conflict. Work only on the named branch/worktree and scope. Run configured gates, report exact results, update handoff, and do not declare completion until review requirements are met.
